## Response Section
#### ข้อดี : 
    1. เพิ่มความเร็วในการค้นหา (SELECT) ลดเวลาการค้นหาข้อมูล โดยเฉพาะตารางขนาดใหญ่
    2. ช่วยให้การ Sort และ Filter เร็วขึ้น เช่น WHERE , ORDER BY , GROUP BY
    3. เพิ่มประสิทธิภาพการ Join ทำให้เชื่อมตารางได้เร็วขึ้น
    4. เป็น Unique ได้ เช่น Primay Key หรือ Unique Index

#### ข้อจำกัด :
    1. ใช้พื้นที่จัดเก็บเพิ่ม index ต้องเก็บข้อมูลแยกจากตาราง
    2. ทำให้ Insert/Update/Delete ช้าลง
    3. สร้าง Index มากเกินไป ทำให้ประสิทธิภาพแย่ลง 
    4. ไม่ใช่ทุก query จะใช้ index
